Beyond software, I build real-world hardware-to-software pipelines — connecting BLE devices, cameras, NFC readers, drones, and computer vision into Unity and XR headsets to create physical-to-virtual interactive systems. Eager to contribute innovative solutions and technical expertise to next-generation gaming and simulation projects.

Hardware & Systems Integration

Real-world hardware and sensors connected to Unity, XR headsets, and desktop applications

CBRN Training Simulation (MR)

Desktop-to-Oculus command pipeline where operator commands issued from a desktop build execute as real-time in-headset actions within a Mixed Reality CBRN training scenario.

Head-Tracking Camera Control

Camera-based head-tracking feature where lateral head movement (left/right) directly drives corresponding vehicle/drive movement in a desktop simulation.

NFC-Based Object Recognition

NFC tag-reader system for 3D-printed physical models — scanning an attached NFC tag against a reader auto-displays the model's full information set.

Drone Simulator

Hardware-controlled drone simulator giving full desktop flight control (throttle, pitch, yaw, roll) synced with physical drone hardware.

OpenCV QR-Based Interaction System

OpenCV-powered multi-QR detection system mounted on a physical prop; scanning a QR code through the Oculus headset camera triggers a real-time in-headset action at the targeted point.

ElevenLabs Voice Integration

Multiple AI-generated voice profiles integrated via ElevenLabs across simulation and training applications for dynamic character and narration audio.

Wearable Vitals Streaming

Wear OS app streaming live vitals (SpO2, BPM, step count) from Samsung Galaxy Watch to desktop; reverse-engineered third-party pulse oximeters to stream vitals via BLE to desktop and Oculus.

Physical Cycle → Game Sync

BLE-connected pedal-cycle hardware synchronized with both desktop and mobile games, driving in-game cycling movement across multiple distinct routes.
